# Sequencias de animacao do bomber (usadas junto com bomber_sb6.png).
# Animacoes que nao aparecem aqui tocam como no SB5.
#
#   animacao : quadros por pose : sequencia
#
# animacao  = numero do rotulo da folha (hexadecimal)
# quadros   = duracao de cada pose em quadros de jogo (60 = 1 segundo)
# sequencia = numero da celula da linha (1 = primeira pose)
#   3*20    = pose 3 durante 20 quadros (em vez da duracao da linha)
#   -       = nada desenhado
#   [       = o loop volta para este ponto (sem isto, volta para o comeco)
#   fim     = some e para (ultimo item)
